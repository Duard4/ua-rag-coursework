# Метод підвищення точності пошуку та формування контексту RAG-системи за україномовними документами

Код і результати до курсової роботи (КНУ імені Тараса Шевченка, ФІТ, ОНП «Технології штучного інтелекту»).
Генерація відповіді мовною моделлю в роботі не розглядається: оцінюються два модулі RAG-системи — пошук (M1) і формування контексту (M2).

## Що робить репозиторій
Відтворює експерименти розділу 3:
- E1 — вплив нормалізації (поверхневі форми / леми / префікс-5 / символьні 4-грами) на BM25;
- E2 — семантичні сигнали (LSA, усереднені вектори floret);
- E3 — злиття оцінок: RRF проти опуклої комбінації (CC) з вагами, підібраними на розробній вибірці; ефективність за обсягом розмітки;
- E4 — відбір речень під бюджет слів проти усічення топ-5 документів (усічення золотого абзацу наведено як довідковий рядок);
- E5 — аналіз помилок, парний бутстреп, затримка;
- E6 — трансформерні ембединги (multilingual-e5, BGE-M3) і їх злиття з лексичними системами (`src/colab_e6.py`, GPU).

## Дані
UA-SQuAD (FIdo-AI/ua-squad, розділ train, 13 859 запитань, похідне від SQuAD 2.0; ліцензія успадкована CC BY-SA 4.0):
`https://github.com/fido-ai/ua-datasets/releases/download/v0.0.1/ua_squad_dataset.json` → `data/ua_squad_dataset.json`
(`run_all.sh` завантажує файл сам). Корпус: 2 620 унікальних абзаців. Дані в репозиторій не включено.

## Середовище
Python 3.11, CPU. Версії — `requirements.txt`. Seed = 42 (розбиття за контекстами 30 % / 70 %, бутстреп, підвибірки).

## Запуск
```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
./run_all.sh          # повний конвеєр, ≈ 25 хв на CPU; результати: results/*.json, figures/*.png
```

## Демонстрація (≈ 2 хв)
```bash
python src/demo.py
```
Потрібні лише `data/ua_squad_dataset.json` і `results/retrieval.json` (ваги злиття). Старт ≈ 4 с, пошук ≈ 10 мс на запитання.
Enter показує тестове запитання, де усічення топ-5 документів втрачає відповідь, а відбір речень її зберігає;
можна ввести власне запитання за темами корпусу (буддизм, Шварценеггер, Канье Вест, Плімут тощо) або змінити бюджет командою `b 80`.

## Обмеження
Немає LLM-генерації: якість контексту оцінюється через покриття відповіді в ньому (верхня межа для екстрактивного читача), а не EM/F1.
Один набір даних (переклад SQuAD 2.0) і одна мова. E4 виконано на конфігурації без нейромереж; повторення з BGE-M3 — окремий скрипт (див. нотатки до диплома).
